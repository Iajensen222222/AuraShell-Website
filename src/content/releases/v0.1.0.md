The first public alpha of AuraShell. Core modules are implemented and the test
suite is green; the focus of this release is collecting feedback from early
testers on stability, performance, and the WinUI 3 shell.

## Highlights

- **Real-time audio visualizer** — DirectX 11 FFT spectrum rendered at 60 FPS with under 50 ms input-to-pixel latency.
- **Desktop icon changer** — drag any image onto a shortcut to replace its icon. Per-icon, fully reversible.
- **Taskbar hover animations** — kinetic spring physics and scale effects, opt-in per workspace.
- **Workspace theming** — each virtual desktop can carry its own visual identity.
- **WinUI 3 shell** — five immersive pages (Home, Visuals, Behavior, Desktop, Settings), all native, no Electron.
- **One-click uninstall** — every file and registry entry is removed cleanly.

## Known limitations

- This is an alpha release and is not yet code-signed; expect a Windows SmartScreen warning on first run until the signing strategy lands.
- The Microsoft Store and winget package submissions are gated on a signed installer.
- The audio visualizer requires WASAPI loopback to be enabled (Windows 11 default).
